# DormLife

Мобильный и веб-интерфейс студенческого общежития на Expo SDK 54, React Native и Expo Router.

Дизайн: тёплый светлый фон, сливовый и лаймовый акценты, крупная типографика, фотографии и карточки пространств. Направление вдохновлено Student Roost; логотип, тексты и компоненты принадлежат DormLife. Прямой доступ к сайту-референсу во время разработки был недоступен, поэтому это самостоятельная интерпретация, а не точная копия.

## Запуск

Нужен Node.js 24 или новее.

~~~bash
npm ci
npm run web
~~~

Для Expo Go или development build:

~~~bash
npm start
~~~

Телефон должен иметь доступ к компьютеру с Metro. Локальный запуск веб-версии не требует API, паролей или внешних сервисов. Фотография и шрифт иконок включены в проект, внешние CDN не нужны.

## Что работает

- Главная: быстрые действия, счётчики собственных заявок и планов, карточки с советами.
- Заявки: выбор категории, проверка описания, сохранение черновика и удаление с подтверждением.
- Бронирование: четыре типа пространств, три стиральные машины, выбор дня и часового сеанса на ближайшую неделю. Прошедшие часы и пересекающиеся собственные планы недоступны.
- Профиль: имя, комната и необязательная почта с проверкой формата.
- Данные переживают перезапуск благодаря AsyncStorage. Изменения отображаются только после успешного сохранения; ошибки хранилища не выдают ложное подтверждение.
- На узком экране появляется нижняя навигация, на широком — меню в шапке. Прямые ссылки ведут к соответствующим страницам.

## Границы текущей версии

Это интерфейс с локальным хранением, без сервера и регистрации. Заявки не отправляются сотрудникам. Планы не резервируют ресурс у администрации и не учитывают занятость других жильцов. Эти ограничения обозначены на соответствующих экранах.

Профиль не является подтверждённой учётной записью. Данные не синхронизируются между устройствами и вкладками; очистка данных приложения/браузера удаляет их. Пароли и другие секреты хранить здесь не следует.

Интерфейс сейчас на русском. Реальные роли администратора/сотрудника, серверная авторизация, общая занятость, уведомления и казахская локализация требуют отдельной реализации. Старый README описывал эти функции, но их исходного кода в этом checkout не было.

## Проверки

~~~bash
npm run typecheck
npm run lint
npx playwright install chromium
npm test
~~~

Playwright сам запускает Expo на порту 8082, если он свободен. Для установленного системного Chromium можно задать переменную PLAYWRIGHT_CHROMIUM_EXECUTABLE (например, /usr/bin/chromium). Сценарии выполняются в изолированных браузерных контекстах для компьютера и телефона: навигация, проверка форм, сохранение после перезагрузки, удаление, пересечение времени и ошибки хранилища.

Сборка JavaScript и ресурсов без нативного SDK:

~~~bash
npx expo export --platform android --output-dir .expo/android-check
npx expo export --platform web --output-dir dist
~~~

Это не сборка APK и не проверка рендеринга на физическом устройстве.

## Структура

- src/app/ — маршруты и экраны.
- src/components/ — оболочка приложения и общие элементы интерфейса.
- src/lib/store.tsx — типы, локальное хранилище и последовательное сохранение.
- src/lib/theme.ts — цветовая палитра.
- tests/ — браузерные сценарии.
- assets/images/ — локальная фотография с лицензией и указанием источника.
