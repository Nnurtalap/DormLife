# DormLife

Приложение общежития на Expo SDK 54 / React Native / Expo Router. Языки: қазақша и русский. Профили, заявки и бронирования хранятся в SQLite на компьютере. Демопользователей и демонстрационных заявок нет.

## Запуск

Нужен Node.js 24 или новее.

```powershell
npm install
npm run web
```

Команда запускает сервер базы на порту 3001 и Expo. Откройте напечатанный Expo адрес (обычно http://localhost:8081). Не закрывайте терминал. Для телефона: `npm start`; телефон и компьютер должны находиться в одной сети. После добавления нативных модулей пересоберите свой development build командой `npx expo run:android` либо через EAS.

Сервер отдельно: `npm run server`. Для другого адреса API задайте `EXPO_PUBLIC_API_URL` в `.env.local` и перезапустите Expo. Например, `http://192.168.1.10:3001`. Туннель Expo не открывает доступ к API автоматически.

## Вход и регистрация

При запуске открывается вход по почте и паролю. Новый студент нажимает «Регистрация студента», заполняет данные, выбирает свободную комнату и задаёт пароль от 8 до 128 символов с подтверждением. После регистрации выполняется вход. Регистр почты и пробелы по краям не влияют на её уникальность.

В профиле доступна кнопка «Выйти из аккаунта». Выход отзывает текущую серверную сессию и очищает личный кэш, сохраняя сам аккаунт и настройки оформления. История навигации не открывает закрытые экраны повторно. При выходе без сети приложение сразу скрывает личные данные и сохраняет запрос на отзыв сессии до восстановления соединения. Вход на других устройствах сохраняется.

Сессия действует 30 дней и восстанавливается после перезапуска, если не была отозвана. В браузере используется HttpOnly cookie, на Android/iOS — SecureStore. Пароли на устройстве не сохраняются, в SQLite хранится только scrypt-хеш с отдельной случайной солью. Сервер определяет роль и пользователя по сессии, проверяет права на каждое действие и ограничивает частоту попыток входа. Публично доступно только число свободных мест; заявки, контакты и бронирования требуют входа. Студент видит собственные заявки и брони; чужая занятость ресурсов передаётся без владельцев.

## Ранее созданные профили без пароля

При первом запуске новой версии сервер сохраняет исходный снимок в `server/data/dormlife.sqlite.before-auth-<время>.json`, удаляет восемь демопользователей и их примеры. Зарегистрированные студенты, их личные данные, заявки, фотографии и бронирования остаются. Записи истории от удалённых демосотрудников сохраняются как архивные; незавершённые заявки возвращаются на назначение реальному сотруднику.

Старому профилю необходимо установить пароль. На компьютере владельца базы выполните:

```powershell
npm run account -- --email student@example.kz
```

Команда выдаёт одноразовый код, действующий 24 часа. Передайте его только владельцу указанного аккаунта. На экране входа нажмите «Установить пароль по коду», введите почту, код и новый пароль с подтверждением. Профиль и занятое им место сохранятся; второй профиль не создаётся. После активации код перестаёт работать. Новая выдача кода отменяет предыдущий. Для активированного аккаунта эта команда не позволяет обойти пароль.

## Настоящие администраторы и сотрудники

Общедоступная регистрация всегда создаёт студента. Администратора или сотрудника добавляет владелец базы из терминала:

```powershell
npm run account -- --role admin --name "Имя администратора" --email admin@university.kz --phone "+77001234567"
npm run account -- --role staff --name "Имя сотрудника" --email staff@university.kz --phone "+77001234568"
```

Каждая команда создаёт реальный профиль и выдаёт одноразовый код для установки его пароля. Автоматических учётных записей и общих паролей нет.

## Комнаты и бронирования

Регистрация занимает одно место в выбранной комнате. Заполненные комнаты исчезают из выбора. Данные обновляются примерно за три секунды; почта и вместимость повторно проверяются в транзакции перед сохранением.

Три стиральные машины, кухня, учебная комната и комната отдыха бронируются на час. Бронь уменьшает доступное число часов; отмена будущей брони освобождает час. Один студент не может занять разные ресурсы одновременно. Повтор сетевого запроса не создаёт вторую запись.

Файл базы `server/data/dormlife.sqlite` и резервные копии исключены из Git. Не удаляйте базу при перезапуске. Резервные копии снимайте при остановленном сервере. Настройки языка, темы и размера шрифта сохраняются отдельно для каждого аккаунта на устройстве.

Локальный HTTP используется для разработки в доверенной сети. Для доступа через интернет нужны HTTPS и настройка разрешённых веб-источников `DORMLIFE_WEB_ORIGINS` (адреса через запятую); за HTTPS-прокси задайте `DORMLIFE_COOKIE_SECURE=true`. Не публикуйте файл базы и резервные копии. Сброс забытого пароля и отправка писем пока не реализованы; обычный вход, выход и первоначальная активация работают без почтового сервиса.

## Проверки

```powershell
npm test
npm run lint
npm run typecheck
npx expo install --check
```

Тесты проверяют отсутствие демоданных, миграцию и резервную копию старой базы, уникальность почты, пароли и сессии, отзыв при выходе, разграничение прав, одноразовые коды, конкурентную регистрацию, бронирование и полный цикл заявки.
